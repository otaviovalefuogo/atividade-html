Estudos em Desenvolvimento Web

Como estudar Desenvolvimento Web

  1. Aprender a estrutura básica do HTML5.
  2. Estilizar as páginas utilizando CSS3.
  3. Adicionar interatividade com JavaScript.
  4. Praticar criando projetos reais e pequenos sites.
  5. Aprender a utilizar o Git e publicar projetos no GitHub.

Ferramentas utilizadas

  • Visual Studio Code (VS Code)
  • Navegador Google Chrome (com DevTools)
  • Git e GitHub
  • Figma (para prototipagem de layouts)
